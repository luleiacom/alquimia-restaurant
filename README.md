# Alquimia Speakeasy & Interactive Laboratory

> *An immersive web application blending clandestine bar culture with interactive mixology, atmospheric soundscapes, and digital gamification.*

## Project Features

* **Clandestine Access Portal:** Entry screen requiring a secret password or terminal command to unlock the secret lounge.
* **Dynamic Flashlight Effect:** Interactive visual effect using the cursor (`onMouseMove`) to uncover hidden elements in the dark.
* **Ambient Audio:** Integrated audio player using a local audio file (`music1.wav`) to build an immersive atmosphere.
* **Interactive Compendium:** Visual menu showcasing signature craft elixirs with photography and informative modals.
* **Alchemical Cauldron:** Interactive laboratory where users can select ingredients to synthesize custom potions and formulas.
* **Telegraph Terminal:** Retro command-line console to interact with the system (`help`, `vip`, `status`, `stamps`).
* **Digital Passport:** Persistent achievement system using `localStorage` to collect mystical stamps.

---

## Technologies Used

* **React (Vite):** Component-based frontend architecture and state management.
* **Tailwind CSS:** Modern utility-first styling tailored for dark and sleek interfaces.
* **Web APIs:** HTML5 audio management and advanced interactivity.
